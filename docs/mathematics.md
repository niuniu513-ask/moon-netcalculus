# 模型、算法与有效范围

令输入满足到达曲线 `α(t)=b+rt` (`t>0`)，且 `α(0)=0`。服务曲线 `β(t)=R max(0,t-T)`，其中 `b,r,T≥0`，`R>0`。这些是模型约束，调用者须提供其有效性依据。

## 全时域解析界

当 `r≤R` 时，垂直偏差 `sup_t(α(t)-β(t))` 为 `b+rT`，水平偏差为 `T+b/R`。零流量 `b=r=0` 的 backlog 与 delay 均取零。速率相等仍具有确定性有限上界；不要套用随机稳态排队模型必须严格低于容量的条件。

输出到达包络可取 `(b+rT,r)`。它由全时域 deconvolution 定理得到，而非从离散曲线的有限窗口外推。

到达聚合为逐项相加。串联系统的服务曲线是各服务曲线的 min-plus 卷积；对速率—时延族可取 `(min_i R_i, sum_i T_i)`。因此端到端分析对本流突发只支付一次；它可能优于把每跳延迟直接相加，但不声称全局最紧界。

对于严格服务器 `β_R,T`，交叉流量 `α_bc,rc` 在任意复用下留下 `max(0,β-α_cross)` 的严格剩余服务。若 `R>rc`，一个速率—时延表示是：

```
R_left = R - rc
T_left = (R*T + bc) / (R - rc)
```

没有统计独立性假设。若剩余服务不为正或目标流速率高于它，返回 `Unbounded`；它表示当前模型无法给出有限保证，不代表已经观测到系统故障。

单服务器预算反解：需 `buffer_limit≥b+rT`。非零突发需 `D>T`，最小容量为 `max(r,b/(D-T))`。零突发且非零速率可取 `R=r`，要求 `D≥T`；空流量的最小需求为零，该需求值不代表一个可构造的正速率服务器。

## 前馈网络

取所有流路径形成的边并集，拓扑排序。每个节点先保存所有输入包络，再对各目标流求其他流包络之和与剩余服务。各流离开节点后，按该剩余服务的延迟传播突发。后续节点使用传播后的交叉流量包络，不重复使用入口突发。

每流的剩余服务可串联得到一个端到端服务曲线，入口包络与之计算得到 `end_to_end`；`sum_hop_delay`、`maximum_hop_backlog` 与逐跳传播得到的 `exit_envelope` 另外报告。`end_to_end.backlog` 是相对于端到端等效系统的聚合 backlog 界，不应当作任一具体节点所需的缓冲区；节点缓冲区应看 `hops[].metrics.backlog`。`end_to_end.output` 与 `exit_envelope` 是两种保守包络，不要求数值相等。

输入流顺序不影响各流结果。无关可用节点之间按声明顺序打破拓扑排序平局。节点/流 ID 区分大小写，未知、重入及联合环路拒绝。当前只实现基于保守交叉流量包络的前馈分析；没有 PMOO、FIFO 专用界、固定点求解、TSN 调度器模型或最优路由规划。

## 有限离散曲线

曲线是非负、非递减数组且 `f[0]=0`；构造与取样均复制数据。

```
(f ⊗ g)[t] = min_{0≤u≤t}(f[t-u]+g[u])
window(f ⊘ g)[t] = max_{0≤u≤H-t}(f[t+u]-g[u])
f*[0] = 0
f*[t] = min_{1≤u≤t}(f[u]+f*[t-u])
```

卷积在离散网格的已知前缀内精确枚举候选，但没有连续插值含义。反卷积的候选集合随 t 缩小，不保证单调，且缺失未来候选意味着它不能提供全时域上界。闭包用动态规划计算，与所有正整数分解穷举对照。

窗口 backlog 为 `max_{0≤t≤H}(α[t]-β[t])`；水平偏差搜索服务首次追上该时刻累计到达量的网格点。任一到达采样在 H 内不能被服务覆盖，就把全前缀延迟上界标为未知，并保留已解决采样最大值。离散未观察区间和 H 之后的部分完全不在结论范围内。

## 事件契约

事件序列按非递减时间排列，值为瞬时工作量增量。枚举全部连续子序列 `(i..j)`，检查 `sum(amount[i..j])≤b+r*(t_j-t_i)`。这与流体定义在事件端点的左右极限一致：单事件及相同时刻的多个事件仍受到突发 b 的约束，不能因 `α(0)=0` 抹去瞬时突发。

固定 rate 的最小观测 burst 是上述区间的 `max(sum-r*duration,0)`，并保留见证。经验包络查询对任意窗口取所有跨度不大于该窗口的事件区间总量最大值。没有事件间的额外流量被推测，没有渐近 rate 被拟合。

## 复杂度与验证

解析操作 O(1)，串联/聚合 O(K)；离散卷积、闭包、偏差及窗口反卷积至多 O(H²)；事件契约/拟合 O(N²)，经验包络采用滑动窗口 O(WN)。网络拓扑 O(V²+总路径长度)，每节点交叉流量计算 O(F²)。规模限制先于大数组构造和枚举。

行为验证除 MoonBit 用例外，还包括独立 Python 流体累计量/服务量演算、所有离散整数分解、全事件区间穷举和拓扑置换不变量。数值是 Double 求值，不等于实数算术的认证包络。
